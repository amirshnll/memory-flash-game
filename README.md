# Memory Flash

## Short description

Watch, remember, and repeat an expanding sequence.

## Description

Memory Flash is an accessible, multilingual sequence-memory game for the browser. It presents an increasingly long pattern of tiles for the player to reproduce and includes multiple game modes, sound controls, numbered tiles, reduced-motion support, and local high scores.

## Purpose

The extension provides short memory and concentration exercises that are easy to start from the browser toolbar and suitable for repeated practice.
